# TBHRC

One unified, multi-tenant GitHub organisation for **Talent Bridge** and **iMPLEMENTAi**, running side by side with shared departments and shared specialist foundations. Repositories are department / function / product owners, not internal secrecy boundaries.

## Start here

- **Organisation map, chart & structural pre-structure** → [`tbhrc/org`](https://github.com/tbhrc/org)
- **Repository map (active ops + active product lines)** → [`org/300-governance/repository-map.md`](https://github.com/tbhrc/org/blob/main/300-governance/repository-map.md)
- **Reusable HOW — skills, policies, workflows** → [`tbhrc/skills`](https://github.com/tbhrc/skills)
- **Neutral identity / data** → [`tbhrc/db`](https://github.com/tbhrc/db)

Open a repository's root `AGENTS.md` first — it is the router for work in that repository.
