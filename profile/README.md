# TBHRC

One unified, multi-tenant GitHub organisation for **Talent Bridge** and **iMPLEMENTAi**, with `tbhrc/workspace` as the primary human-and-AI organisational operating workspace. Independent repositories remain where a real technical, product, data, security, public-distribution, client or deployment lifecycle earns the boundary.

## Start here

- **Organisation structure, businesses, departments, operations and migration map** → [`tbhrc/workspace`](https://github.com/tbhrc/workspace)
- **Organisation master router** → [`workspace/AGENTS.md`](https://github.com/tbhrc/workspace/blob/main/AGENTS.md)
- **Workspace migration / retained-repository decisions** → [`MIGRATION-PLAN.md`](https://github.com/tbhrc/workspace/blob/main/MIGRATION-PLAN.md)
- **Reusable HOW — Skills, policies, workflows** → [`workspace/.folderdesk/skills`](https://github.com/tbhrc/workspace/tree/main/.folderdesk/skills)
- **Neutral identity / data** → [`tbhrc/db`](https://github.com/tbhrc/db)

Open a repository's root `AGENTS.md` when one exists; it is the local overlay beneath the Workspace master router. `tbhrc/skills` is retired provenance/compatibility only.
