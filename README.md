# .github

Organisation-wide GitHub platform defaults and governance surfaces for the TBHRC organisation.

- [Organisation custom instructions](ORGANIZATION-CUSTOM-INSTRUCTIONS.md) — versioned source for the native GitHub Copilot organisation-level instruction setting; points to the Workspace master router rather than duplicating it.
- `.github/` — shared issue/PR/community-health defaults where supported.
- `CODEOWNERS` — ownership defaults.
- `profile/` — organisation profile content.

Organisation-wide routing is owned by [`tbhrc/workspace/AGENTS.md`](https://github.com/tbhrc/workspace/blob/main/AGENTS.md). Reusable operating HOW is owned by [`tbhrc/workspace/.folderdesk/skills/`](https://github.com/tbhrc/workspace/tree/main/.folderdesk/skills); this repository owns only GitHub-platform/default delivery surfaces.
