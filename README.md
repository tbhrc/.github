# .github

Organisation-wide GitHub platform defaults and governance surfaces for the TBHRC organisation.

- [FolderDesk organization custom instructions](ORGANIZATION-CUSTOM-INSTRUCTIONS.md) — versioned source for the native GitHub Copilot organisation-level instruction setting; points to the canonical FolderDesk Master Prompt rather than duplicating it.
- `.github/` — shared issue/PR/community-health defaults where supported.
- `CODEOWNERS` — ownership defaults.
- `profile/` — organisation profile content.

Reusable operating HOW remains in [`tbhrc/skills`](https://github.com/tbhrc/skills); this repository owns GitHub-platform/default delivery surfaces.
